# Scope Boundaries & Deferred Backlog

## Initial Build Scope (Sprints 1–2)
- Manual symptom entry.
- Four guided checks per problem category (Slowdown and Connectivity).
- Saved answers (including 'unknown' and 'not tried').
- Case history and notes.
- JSON export and deletion.
- User-reported resolution and escalation status.
- Windows 11 personally owned devices only.

## Sprint 3 Addition
- Structured measurements and before/after comparisons (not in initial build).

## Later Releases (Sprints 4–8)
- Live model calls with evidence grounding.
- Customer accounts and support queue roles.
- Paid assisted support sessions.
- Screenshot uploads with privacy controls.
- Diagnostic file ingestion and broader OS/device support.

## Explicitly Excluded
- Remote desktop control.
- Background device access.
- Automatic repairs and registry edits.
- Destructive cleanup.
- Password collection.
- Claims that a device has been scanned when it has not.
