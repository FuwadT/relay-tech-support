## User outcome
AI outputs are constrained to structured explanations and pre-approved check IDs rather than uncontrolled code or advice.

## Implementation scope
Specify allowed inputs and structured outputs in `lib/contracts.ts` (`AIExplanation`, `AIExplanationProvider`).

## Deliverable
Structured contract prohibiting executable code and restricting recommended checks to approved IDs.

## Acceptance checks
- [ ] **Observable expected behavior**: Done when the model proposes explanations and approved check IDs rather than arbitrary executable actions.
- [ ] **Relevant failure behavior**: Handled gracefully with controlled recoverable errors; invalid requests rejected and progress not lost.

## Verification evidence
Verified by `tests/s5-ai-integration.test.ts` (test 'S5-01 model contract strictly constrains outputs to approved check IDs and schema').
