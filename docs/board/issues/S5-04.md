## User outcome
If AI times out or errs, the application gracefully falls back to deterministic guided rules without blocking the user.

## Implementation scope
Handle invalid responses, timeouts, and unavailable providers via `generateDeterministicAIExplanation` in `lib/ai-provider.ts`.

## Deliverable
Deterministic fallback engine guaranteeing 100% availability even with zero provider credentials.

## Acceptance checks
- [ ] **Observable expected behavior**: Done when guided mode still completes the session.
- [ ] **Relevant failure behavior**: Handled gracefully with controlled recoverable errors; invalid requests rejected and progress not lost.

## Verification evidence
Verified by `tests/s5-ai-integration.test.ts` (test 'S5-04 graceful fallback handles invalid JSON, nulls, and provider errors').
