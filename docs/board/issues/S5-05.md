# [S5-05] Add usage controls

**Owner**: Platform agent  
**Estimate**: 90 min  
**Dependencies**: [S5-02](S5-02.md)  
**Sprint**: [Sprint 5 — Live AI explanations](../sprints/S5-ai-integration.md)  
**Status**: In progress

---

## User outcome
Protection against runaway costs, click-spamming, and oversized prompts with rate limits.

## Implementation scope
Limit request frequency, input size, and per-case usage (max 5 requests per case, 3s cooldown) in `lib/ai-rate-limiter.ts`.

## Deliverable
Rate limiter returning HTTP 429 when budget or cooldown limits are breached.

## Acceptance checks
- [ ] **Observable expected behavior**: Done when repeated clicks cannot create unlimited requests.
- [ ] **Relevant failure behavior**: Handled gracefully with controlled recoverable errors; invalid requests rejected and progress not lost.

## Verification evidence
Verified by `tests/s5-ai-integration.test.ts` (test 'S5-05 usage controls enforce per-case limits and cooldown periods').
